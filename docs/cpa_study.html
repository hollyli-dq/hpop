CPA Study — Canonical Procedural Actions for Coding-Agent Traces

HPOP · weak-supervision layer for partial-order skill induction · 500 SWE-rebench/OpenHands trajectories (334 repos) · generated from the analysis scripts in scripts/
Executive summary
  • What a CPA is: a canonical procedural action — the procedural function of a trace span (e.g. RUN_TEST_SUITE), more abstract than a tool call, portable across repos. CPAs are the action vocabulary that gives the HPOP model structured weak supervision.
  • Two ways to build them: v1 = bottom-up induction from data (29 CPAs); v2 = top-down derivation from a 9-phase cognitive taxonomy (Miller & Cohen 2001), 32 CPAs. v2 also adds a per-occurrence cognitive phase label.
  • Are the labels meaningful? Against a no-instruction floor (label by raw command, no taxonomy → 0.58 bits of structure), the guided schemes reach 0.94–0.98 bits — and far more efficiently per symbol. The annotation is real, not an artifact of vocabulary size (each scheme is null-calibrated against its own shuffle).
  • v1 vs v2: a near-tie on structure; v2 is slightly better (0.979 vs 0.940 excess bits, highest per-symbol efficiency 0.201) and adds the cognitive phase layer that the head-to-head shows is more self-predictable than the raw physical layer.
  • Does the guidance matter? Honestly: only modestly for raw structure (a smart no-instruction "act+object" labeling reaches 0.918 vs guided 0.979). The instruction's decisive win is vocabulary control: it splits the over-loaded python (33% of all events) by intent and merges repo-specific synonyms into reusable types.

1 · Corpus & pipeline

Benchmark: nebius/SWE-rebench-openhands-trajectories. We sampled 500 trajectories across 334 repositories (five pilots of 100; 50 resolved + 50 unresolved each), deliberately diverse in length and outcome.

The pipeline follows the linguistics coauthor's layered framework (PDAF v3):

StepLayerWhat it doesGrounding
1 · normalizeB · 1aeach event → action token (action_type, tool_family, agent_id, artifact_id); collapse adjacent identical actions; normalize tool namesISO 24612:2012 LAF · Bird & Liberman 1999
2 · phase tagAeach span → one of 9 cognitive phases (the control state) — assigned first, the primary labelMiller & Cohen 2001
3 · CPAB · 1bwithin each phase, refine to the specific CPA (the procedural action realizing that control state)Leontiev 1978 (Activity Theory)

Phase-first (coarse → fine). Consistent with the top-down method — phases generate CPAs — the annotation assigns the cognitive control state first (9 robust categories), then refines to the specific CPA within that phase. The phase is the primary, more robust label; the CPA is its within-phase specialization.

Step 1 result: 32,664 raw events → 30,548 action tokens (2,116 repeated actions merged), 72% carrying an artifact_id. Steps 2–3 produced 23,929 labeled occurrences (phase + CPA).

Empty phases are a finding, not a gap: single-agent coding traces do not plan overtly, integrate across sources, or hand off — a bottom-up method could never have told us that.

3 · Evaluation methodology

"Is this a good annotation?" is operationalized as: how much sequential structure does the label sequence carry beyond chance? A good vocabulary makes the trace predictable — the current label tells you about the next.

Transition mutual information over all adjacent label pairs:
I(Lt;Lt+1) = Σ p(x,y) · log2[ p(x,y) / (p(x)·p(y)) ]  bits
Shuffle null: shuffle each trajectory's labels in place (keeps length + composition, destroys order), recompute, average → I_rand. excess = I_real − I_rand removes finite-sample noise, crediting only genuine ordering structure.

The shuffle-null is itself the calibration: every scheme is scored against its own shuffled labels, so excess credits only real sequential structure, independent of vocabulary size or sequence length. The honest floor is the no-instruction labeling (what an annotator produces with no taxonomy), not artificial noise.

Reading the ladder: no-instruction cmdword 0.58 → actobj 0.92 → guided CPA 0.98. Each rung of theory adds measurable structure. (The 9-phase layer is a coarser aggregation of the CPA, not an alternative occurrence labeling, so it is compared separately below — not in this ladder.)

Efficiency (eff) is the cleanest separator. The naive command-word baseline is half as efficient (0.098) — its 62-label sprawl buys little structure per symbol. v2 CPA is the most efficient labeling (0.201), edging the act+object baseline (0.200) and v1 (0.196): the cognitive guidance packs the most non-random structure into the fewest, most reusable symbols.

At nearly equal vocabulary (5 vs 6), the cognitive phase layer is ~2× more self-predictable than the raw physical layer, and a current phase reveals more about the next physical action (0.253 b) than the current physical action does (0.159 b) — the abstraction explains the surface, not vice-versa.

Honest caveat: predicting task success (resolved) from label profiles gives AUC ≈ 0.60–0.66 for all layers — task success is only loosely tied to procedural labeling, so it is not a good utility metric and we do not rely on it.

5 · Why "no instruction" fails — the command-word evidence

Labeling each event by its literal leading command (no taxonomy) sprawls to 62 labels that fail in two opposite ways:

Over-collapsed — generic words swallow distinct functions:
python  7877  (33% of all events — hides repro vs test vs typecheck vs -c)
edit:view 6027   edit:create 2780   grep 2407
Over-fragmented — a long tail of repo-specific junk that aren't categories:
sqlfluff · zpretty · showyourwork · streamlink · hpxml2hescore · sqllineage · fitsinfo · charmcraft_developer · datalad_credential_mike_token · database_url · django_settings_module · tox4 · node · docker … (each 1–3 occ)

The instruction is exactly what repairs both: it splits python by context into REPRODUCE_ISSUE / RUN_TEST_SUITE / CHECK_TYPES, and merges the synonym tail (pytest, tox, nosetests, py.test) into one reusable RUN_TEST_SUITE. Transition-MI barely sees this; HPOP — which learns reusable skills from a controlled, consistent CPA vocabulary — depends on it entirely. (Phases are an optional coarse descriptor for interpretability, not the model's skill types; HPOP consumes CPA occurrence sequences and learns local partial-order skills that may span phases.)

6 · Conclusions

  1. The annotation is real. Against the no-instruction floor (0.58), the guided schemes reach 0.94–0.98 bits of null-calibrated structure. Neither is accidentally structured.
  2. v2 (cognitive) ≥ v1 (induced). Slightly more structure (0.979 vs 0.940 excess bits) and the highest per-symbol efficiency (0.201), plus the phase layer.
  3. Theory beats surface, but modestly on structure. A smart no-instruction "act+object" labeling reaches 0.918 — within 6% of guided. Don't over-claim a structure advantage.
  4. The decisive value of instruction is vocabulary control. It de-conflates the 33%-dominant python and consolidates a 62-label surface sprawl into a reusable, consistent set — the property HPOP actually requires.
  5. Empty cognitive phases are informative. PLAN / SYNTHESIZE / HANDOFF = 0 quantifies that single-agent coding traces don't plan overtly, integrate across sources, or hand off.
