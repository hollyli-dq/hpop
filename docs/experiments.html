HPOP.  Experiments & findings

First executable test of the recurrent frontier likelihood + merge-only semi-Markov segmentation  ·  4 experiments · 52 tests · markdown write-up · ← dashboard
Before this work src/hpop/inference/ held only the flat, non-recurrent, hard-poset BPOP likelihood — none of the manuscript's new claims could be run. Both new components are now implemented, tested against brute-force enumeration, and evaluated on synthetic ground truth and the real SWE-rebench pilot.

Data sources & experimental setup — read this before the numbers

The real-data CPA labels are silver, not gold. pilot100.sequences.jsonl was produced by hpop.annotate.rule_apply (annotator tag rule_apply_seed-v0) — a deterministic rule-based stand-in for the LLM open-coding, mapping each event to a seed CPA from tool name + command keywords + failure context + one bit of state. All 5,012 occurrences are MATCH_EXISTING at a constant confidence = 0.75; no LLM annotation, no human adjudication, no PROPOSE_NEW, no ABSTAIN. This biases the real-data comparison towards the bigram: a deterministic tool→label rule makes local transitions unusually predictable. It does not erase the negative result, but the experiment must be rerun on LLM-annotated CPAs before the conclusion is final.

Both models improve with data and the gap stays at ~0.34 nats throughout. The bigram's advantage is representational, not a large-sample effect: with 16 CPA types the transition table is cheap to estimate, and a partial order deliberately throws that information away. Inside a skill, log F̃ ≈ 0 wherever the poset has no edge, so with sparse structure the step distribution collapses towards a per-skill unigram with a mild validity adjustment.

C · Why the latent graph stays acyclic while execution repeats

The repair loop is not a cycle in the partial order. It is re-execution driven by the validity state q_t: running an upstream role invalidates everything it dominates, and the stale roles must be recomputed. This is the component whose removal costs 0.17 local edge F1 in experiment ①.
What this figure also exposes. Under the manuscript's J̃ = DU·σ(ω), invalidation flows only forward along precedence — so the jump back to EDIT at step 5 is never predicted, only charged λrep. A failed test cannot invalidate the edit that preceded it. That is finding (b), and this is what it looks like.

④ Invariance to legal reorderings — the claim that should favour partial orders

Next-occurrence likelihood rewards memorizing the serialization the agent happened to use. The claim that motivates partial orders is different: two executions differing only in the order of incomparable actions are the same program. Tested non-circularly — incomparability read from the ground-truth local posets, never from the fitted model. 6 seeds × 40 traces, all available swaps.

The hypothesis that HPOP wins here is not supported. HPOP is invariant to legal reorderings — 0.0004 ± 0.0005 nats, indistinguishable from zero and 5× more tightly concentrated across seeds than the bigram — and it strongly rejects dependency violations. But the bigram does about as well: with 12 CPA types and enough traces it simply observes incomparable pairs in both orders and learns both transitions.
The one unambiguous result: HSMM discrimination collapses to 0.001. With segmentation and composition but no order, violation-sensitivity vanishes entirely — confirming that the partial order, not the skill segmentation, is what makes HPOP sensitive to broken dependencies.

Seven issues found in the manuscript

Each came out of implementing the equations as written; each is backed by a test.
(b) Invalidation cannot start a repair loop  most important
J̃(z,x) = DU(z,x)·σ(ωzx) is masked by precedence, so invalidation only flows forward. A failed test can therefore never invalidate the edit that preceded it — the very edit–test–repair cycle the section is motivated by. Under the model the loop's restart is an unexplained move charged λrep; only the recompute cascade after it is explained. In software traces the trigger is observable (the test's exit status), so the fix is to condition invalidation, or λrep, on the observed outcome of the preceding occurrence.
test_invalidation_only_flows_along_precedence
(a) Eq. (recurrent-step-likelihood) has no noise floor
With a hard precedence matrix — or any relaxed DU saturating at 1 — F̃RFS(x) is exactly 0 whenever a predecessor is stale, so an order-violating observation has probability 0 and the log-likelihood is −inf. BPOP avoids this with an ε trembling-hand term; the recurrent likelihood as written drops it.
test_eps_zero_gives_violations_zero_probability
(c) λrep is not a local repeat cost
It penalizes every currently-valid item at every step, not just the one that repeats. Raising it suppresses all valid competitors and can therefore increase the likelihood of a trace containing repeats — verified on a 5-step trace where λrep=4 scores higher than λrep=0. It is a global reshaping of the step distribution and should not be interpreted, or identified, as "the cost of repeating".
test_repeat_cost_does_not_lower_whole_sequence_likelihood
(d) The ELBO's segmentation prior is unnormalized
Eq. (structured-segmentation-elbo) carries Σl[log πz_l − λseg] without dividing by its partition function over the seed lattice, so the implied prior does not sum to 1 and raw log Z is not a likelihood. Still a usable training objective, but held-out numbers are not comparable across models or λseg settings. The implementation reports log p(x) = log Z(score) − log Z(prior), the exact marginal likelihood.
test_uniform_model_gives_exact_uniform_likelihood (recovers −T·log V exactly) · test_likelihood_is_invariant_to_the_segment_penalty
(e) The amortized inference network is unnecessary — this strengthens the paper
Both the model and the variational family in Eq. (structured-semi-markov-posterior) are semi-Markov over the same merge-only lattice, so setting ηφ(a,b,k) = ℓn(a,b,k) makes qφ the exact conditional posterior in O(J·Dmax·K²). Drop the inference network and its hyperparameters and claim an exact structured E-step. (As written, ℓn is defined and then never connected to ηφ — this closes that gap.)
(f) The per-skill weight has no composition term
Fig. (overview) describes each skill by "a CPA-composition distribution and a revisitable local partial order", but Eq. (recurrent-unnormalized-weight) contains only order terms. Two skills over disjoint CPA sets are then distinguished only through order structure, which is weak — EM from θ=0 gives a near-uniform emission model and a flat segmentation posterior. Composition alone already gets HSMM to 0.80 ARI, so this term does much of the identification work and belongs in the equations.
(g) K = 1 is degenerate under Assumption (ass:no-self-transition)
With a single skill slot the no-adjacent-same-label rule makes every multi-segment tiling illegal, so a trace longer than Dmax seeds has probability zero. Harmless in practice; worth a footnote.
test_single_skill_cannot_tile_more_than_D_max_seeds

What to claim instead

  • Keep: structure recovery under known ground truth (experiment ①), the recurrence ablation, the initialization audit (②), compression against order-free and flat models, and the interpretable reusable library recovered without supervision (③).
  • Drop or reframe: held-out next-occurrence likelihood as a headline metric, and n-gram models as the baseline to beat. On this evidence HPOP loses both that comparison and the reorder-invariance comparison.
  • Or fix the model: add a local sequential component alongside the partial order — e.g. a per-skill transition term restricted to the frontier-feasible set — which keeps the order semantics while recovering what the bigram exploits.

Correctness & reproduction

Verified against brute force

  • Semi-Markov log-partition, all segment marginals, Viterbi path and value match exhaustive enumeration of every legal (composition, labelling) pair to 1e-9, over six lattice shapes.
  • Marginals sum to exactly 1 over blocks covering each seed position; closed-form entropy H = log Z − Eq[score] matches the enumerated entropy.
  • Eq. (frontier-equivalence) checked directly: with invalidation off, {x : FRFS(x)=1, q(x)=0} equals the BPOP frontier at every step.
  • Analytic θ gradient matches finite differences; batched library likelihood matches the single-skill implementation to 1e-9.

Scope & limitations of this study

  • The real-data CPA layer is silver. Labels come from a deterministic rule annotator, not the LLM open-coding the manuscript specifies and not human adjudication — constant confidence 0.75, zero PROPOSE_NEW/ABSTAIN, and the 16-type seed library rather than the induced dictionary. Rule-derived labels have artificially regular local transitions, so experiment ③ is biased in the bigram's favour by an unknown amount. Rerunning it on LLM-annotated CPAs is the single most important follow-up before the negative result is treated as settled.
  • Real-data results are a single repository-disjoint split (split seed 0) of 100 trajectories; no error bars across splits. Synthetic results have 5–6 independent seeds.
  • The generator is deliberately not the fitted model — repair loops fire exogenously from verification failures (see finding (b)), so recovery numbers are measured under model mismatch, not in a well-specified setting.
  • Structure estimation uses a weighted first-occurrence pairwise-consensus initializer plus likelihood-guided pruning under the cover-edge penalty — not the reparameterized-gradient optimization of the relaxed DU the manuscript describes (no autodiff available in this environment). The relaxed likelihood itself is implemented and tested; only its gradient-based fitting is substituted.
  • The global order is estimated at the skill-type level, not the instance level. The recurrent likelihood already represents repeated instances of a type without cycles, which suggests the instance-level poset may be avoidable — worth a direct comparison before the paper commits.
  • Held-out NLL conditions on the seed boundaries, which are observed input for every method compared.
