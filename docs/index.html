HPOP.  Hierarchical Partial-Order Skill Programs

Tool-agent traces → induced procedural actions → reusable skills as partial orders → fast DAG inference  ·  project dashboard
Repo: github.com/hollyli-dq/hpop (private)  ·  Primary data: nebius/SWE-rebench-openhands-trajectories  ·  Pipeline built & verified offline; the LLM annotation batch needs an ANTHROPIC_API_KEY.

What this is

Tool-using agents emit long sequential logs even when their behavior is governed by reusable skills, partial dependencies, and repair cycles. We separate data construction from structure learning: an LLM-assisted pipeline induces canonical procedural actions (CPAs) from raw trajectories (CPAs are induced, not predefined), then a hierarchical Bayesian model learns reusable skills (local partial orders) and a global partial order, with a new-skill penalty that regularizes the skill library. The recovered partial order is a DAG — a compiled recipe enabling parallel, search-pruned, reusable inference.

The model — hierarchical Bayesian skill library

  • Skill = a local partial order over CPA instances (BPOP latent U∈ℝ^{m×K}; poset = intersection of K realizers; K via RJMCMC).
  • Library {P_r} ~ DP(α, G₀) — reusable skills shared across the corpus; global partial order over skill instances.
  • Both levels scored by the tractable frontier-softmax (O(T·|A|); avoids #P-hard linear-extension counting).
New-skill penalty (Ewens EPPF): log p(z) = K·log α + Σ log Γ(n_r) + log Γ(α)/Γ(N+α) — each new skill costs −log α; reuse costs log n_r.
Full spec: model_formal.pdf · readable: MODEL.md. Related work: LAST (Fu et al., ICML’24) uses an MDL term for the same compression↔reusability trade-off; BPOP (Li et al.) is the flat single-level base model.
