## B. NON-BLOCKING ITEMS

Worth doing; the paper stands without them.

### B1. TaskBench sensitivity at d = 2
The static fit used `d = 3` latent product-order columns, fixed not fitted.
A `d = 2` rerun would show whether the result is an artifact of latent capacity.
Cheap: 132 fits at ~93 s mean, ~26 min wall on 8 workers. Report as a
sensitivity appendix, not as a new headline.

### B2. β > 0 sensitivity
TaskBench fixed `β = 0`, so the frontier likelihood carries no recurrence
pressure. A small positive β would test whether the external result depends on
that simplification.

### B3. A second real dataset
τ³-Retail is one domain, one agent configuration, one third-party release.
A second real corpus (different domain or different agent) would convert "we
built a pilot" into "the representation transfers".

### B4. Full scalar release
Publish the frozen scalar posteriors and the proposal scales per corpus. This
directly supports the reproducibility claim and costs nothing scientifically.

### B5. Online environment execution
Everything to date scores fixed observed traces. Executing the environment
would test whether inferred structures are *useful*, not merely well-fitting.
This is future work, and the paper should say so explicitly rather than leave
it as an implication.

### B6. Vector figure regeneration
All three TaskBench figures are PNG only. See
`taskbench_figure_manifest.json → vector_regeneration_todo`. Rendering change
only; numerical data must not be altered. Non-blocking for submission,
**blocking for camera-ready**.

### B7. Reconcile the two frozen-report errata
Two frozen `report.md` files disagree with their own JSON (extraction report
discrepancies D4 and D6). Neither changes a conclusion. Either publish an
erratum line in the artifact directory or leave them and rely on the ledger —
but do not silently edit a frozen report.
